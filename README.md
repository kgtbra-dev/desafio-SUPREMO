# 🚀 Template de Desafios JavaScript

Este modelo já vem com o `prompt-sync` configurado para você focar apenas em resolver a lógica do desafio!

---

## 📌 Como usar

1. Abra o arquivo `index.js` e escreva seu código abaixo da linha indicada.
2. Para rodar o programa, abra o terminal nesta pasta e execute:
   ```bash
   node index.js
   ```

---

## 💡 Exemplos de Entrada de Dados

### 1. Ler um texto (String)
```javascript
let nome = prompt("Qual é o seu nome? ");
console.log("Olá, " + nome);
```

### 2. Ler um número (Number)
```javascript
let idade = Number(prompt("Qual é a sua idade? "));
let anoQueVem = idade + 1;
console.log("Ano que vem você terá: " + anoQueVem);
```
